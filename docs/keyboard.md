# Keyboard

Single keys work wherever the document has focus, in the app and in a browser tab
alike.

| Key | Action |
| --- | --- |
| `r` | Toggle rendered / raw |
| `d` | Show / hide the change marks |
| `n` / `j` | Next change |
| `p` / `k` | Previous change |
| `c` | [Check the current change off](changes.md#checking-a-change-off), or bring it back |
| `⇧C` | Bring every checked change back |
| `m` | Mark read |
| `⌘F` | [Find in the document](reading.md#find-in-a-document) |
| `⌘P` | [Print](reading.md#printing) |
| `⌘B` | Show / hide the left sidebar — the open files |
| `⌥⌘B` | Show / hide the right sidebar — contents and history |
| `⌘,` | Settings |
| Space / ⇧Space, Page Up / Page Down, ↑ / ↓, Home / End | Scroll the document |

With a [sidebar's inner edge](reading.md#the-sidebars) focused — tab to it — ← and
→ move it a step at a time and Home / End take it to its limits. The arrows follow
the edge, so on the right-hand one it is ← that makes the column wider.

## The app menu

The native window adds, on top of all of the above:

| Key | Menu | Action |
| --- | --- | --- |
| `⌘O` / `⌘T` | File | Open a file as a tab |
| `⌘N` | File | Open a file in a new window |
| `⇧⌘R` | File | Reveal the file on screen in Finder |
| `⌘P` | File | Print |
| `⌘W` | File | Close the tab — or the window, if it was the last tab |
| `⇧⌘W` | File | Close the window |
| `⌘F` | Edit | Find in the document |
| `⌃⇥` / `⇧⌃⇥` | Window | Next / previous tab |
| `⌘B` | View | Sidebar |
| `⌥⌘B` | View | Contents |
| `⇧⌘V` | View | Rendered / raw |
| `⇧⌘D` | View | Show the change marks |
| `⇧⌘M` | View | Mark read |
| `⌘↓` / `⌘↑` | View | Next / previous change |
| `⌘+` / `⌘-` / `⌘0` | View | Zoom in, out, actual size |
| `⌥⌘T` | View | Always on top |
| `⌃⌘F` | View | Full screen |

**Window ▸ Move Tab to New Window** and **Merge All Windows** have no default keys.
